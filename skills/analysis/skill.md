# Skill: analise e sintese

## Quando usar

Use esta skill para comparar fontes, identificar contradicoes, explicar trade-offs e criar resumos de alta densidade.

## Procedimento

1. Liste as afirmacoes sustentadas por cada fonte.
2. Identifique convergencias, divergencias e ausencia de evidencia.
3. Explique o impacto pratico para a certificacao.
4. Nunca transforme uma inferencia em citacao literal.
