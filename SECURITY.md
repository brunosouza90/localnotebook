# Politica de seguranca

## Reportar vulnerabilidades

Nao publique detalhes de uma vulnerabilidade em issue publica. Envie um relato privado aos mantenedores pelo recurso **Security > Advisories** do GitHub ou pelo contato de seguranca configurado no repositorio.

Inclua:

- descricao do problema;
- passos para reproduzir;
- impacto potencial;
- versao ou commit afetado;
- sugestao de correcao, se houver.

## Segredos

Nunca envie `GEMINI_API_KEY`, arquivos `.env`, `data/study.db`, documentos privados ou tokens para o repositorio. Se uma chave for exposta, revogue-a imediatamente no provedor e gere outra.

## Escopo

Esta politica cobre o codigo e as configuracoes mantidas neste repositorio. Dependencias de terceiros devem ser reportadas aos seus respectivos mantenedores quando a vulnerabilidade nao for causada por este projeto.
